## How to Use This Pack

**Step 1 — Read the slides.**
Open `slides/Week1_OOD_Slides.pdf` and go through it at your own pace.
The slides walk through a single Ride-Hailing App case study from start to finish.

**Step 2 — Run and read the code files in order.**
Each file in `code/` corresponds to a concept from the slides.
Run each file, read the output, then read the source code and comments carefully.

```bash
python 01_design_smells.py
python 02_finding_classes.py
python 03_responsibilities.py
python 04_relationships.py
```

**Step 3 — Attempt the written exercises.**
Open `exercises/Week1_Exercises.md` and work through the questions.
You do not need to submit these — they are for your own preparation.

**Step 4 — Start the lab skeleton.**
Open `exercises/lab_hospital_system.py`.
Read the docstring at the top, then try to implement the `TODO` methods.
Run the file and uncomment `run_tests()` at the bottom to check your work.
